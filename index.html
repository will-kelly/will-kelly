How I work

Pattern recognition beats vendor theater

A stalled AI rollout at one organization connects to the structural reason rollouts stall at fifty. I name the pattern, then the fix. Announcements, pilots that go nowhere, and governance theater get called out, not celebrated.

Documentation debt is a data problem

It wears a technology costume, but the fix is never a new tool. The fix is governance, metadata discipline, and workflows that force prioritization. Teams create documentation debt by deferring those decisions.

Skepticism is the baseline

Enthusiasm has to be earned by evidence. I write for the people who own the budget and the risk, and they've heard enough press releases. If a claim reads like one, I cut it or counter it.
